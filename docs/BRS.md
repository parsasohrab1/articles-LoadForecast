# Business Requirements Specification – LoadForecast

| ID | Requirement |
|----|-------------|
| BR-1 | Forecast next-day hourly load using only information available the day before. |
| BR-2 | Provide 90 % prediction intervals and report their real coverage over time, month by month. |
| BR-3 | Compare a fixed calibration with rolling recalibration when load behaviour drifts seasonally. |
| BR-4 | Report real-data results only; state the limits of a single household without weather input. |

Out of scope: grid-level or ENTSO-E forecasting, weather inputs, probabilistic scheduling, deployment.
